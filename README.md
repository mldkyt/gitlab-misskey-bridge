# Gitlab -> Misskey Bridge

A bridge from Gitlab (using Discord webhooks for real time) to Misskey.

## Setup

1. Build the docker image.
2. Start the docker container with these environment variables: `CHANNEL_ID`, `MISSKEY_INSTANCE`, `MISSKEY_TOKEN` and `DISCORD_TOKEN`.

## Development

1. Fork this project (on Codeberg or git.gay)
2. Make changes to the project
3. Open a pull request. Your pull request will be merged and mirrored to other mirrors.
